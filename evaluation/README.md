# QPE evaluation and structural diagnostic utilities

These utilities are part of [3D Radar Reliability](../README.md).

- `compare_physical_rs_uncertainty.py`: structured radar-observation
  perturbations (noise, vertical and temporal dropout, intensity
  scaling, local echo masking).
- `compare_height_layer_rs_uncertainty.py`: targeted height-level and
  height-group sensitivity.
- `evaluate.py` and related scripts: general QPE evaluation building
  blocks with event and regression metrics.

The top-level `run_evaluation.py` contains model- and
dataset-specific placeholders. It is **not** a turnkey paper
reproduction entrypoint.

Provide your own authorized radar input, labels, loaders and compatible
model weights. The repository includes no original evaluation-result
CSVs, example manuscript statistics or model checkpoints. Results
generated by these utilities stay in user-selected local directories.

For the separate frozen-representation readout methods, see
[PatchShot](../docs/PATCHSHOT_PROTOCOL.md) and
[matched CE](../docs/MATCHED_CE_PROTOCOL.md).
